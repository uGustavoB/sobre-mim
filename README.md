# Sobre Mim 🚀

Página pessoal e portfólio desenvolvido para apresentar minha trajetória, interesses e conhecimentos em desenvolvimento de software.

🔗 **Acesse online:** [https://ugustavob.github.io/sobre-mim/](https://ugustavob.github.io/sobre-mim/)

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias web modernas e sem dependências externas pesadas:
- **HTML5** para a estrutura semântica.
- **CSS3** para estilização, layout responsivo e design system personalizado.
- **JavaScript (Vanilla)** para interatividade e persistência de preferências do usuário.

---

## ✨ Funcionalidades

- **Design Responsivo:** Layout totalmente adaptável para dispositivos móveis, tablets e desktops.
- **Tema Claro / Escuro:** Alternância de tema dinâmica com salvamento automático da preferência do usuário utilizando `localStorage`.
- **Apresentação Pessoal:** Seções dedicadas a introdução, stack de tecnologias/interesses (como Docker, Spock e Micro-serviços) e formas de contato.

---

## 🚀 Como Executar o Projeto Localmente

Se você deseja clonar e executar este projeto na sua máquina, siga os passos abaixo:

1. Clone o repositório:
   ```bash
   git clone https://github.com/ugustavob/sobre-mim.git
   ```

2. Entre na pasta do projeto:
   ```bash
   cd sobre-mim
   ```

3. Abra o arquivo `index.html` diretamente no seu navegador de preferência, ou utilize uma extensão como o **Live Server** (no VS Code) para melhor experiência de desenvolvimento.
